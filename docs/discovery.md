## Prepared launch copy (not posted)

I built GDS Inspector, a free open-source GDSII viewer for the browser and VS Code. It has 2D/3D layer views, hierarchy navigation, KLayout layer colors, measurements and density analysis. Local layouts stay on your machine. You can try the generated EBL example without uploading a file: https://outblade.github.io/gds-inspector/?example=ebl

For ASIC flows, try a SKY130 Tiny Tapeout tile: https://outblade.github.io/gds-inspector/?example=tt

Source and extension downloads: https://github.com/OutBlade/gds-inspector
